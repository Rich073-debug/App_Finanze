# App Finanze

**Apri l'app:** https://rich073-debug.github.io/App_Finanze/
**Guida completa (installazione, MacroDroid, prompt di supporto):** https://rich073-debug.github.io/App_Finanze/guida.html

App web per Android che ti dice ogni giorno quanto puoi spendere, partendo dallo stipendio e togliendo spese fisse, scadenze annuali e risparmi.

- **Budget giornaliero dinamico:** (stipendio + entrate extra − spese fisse − accantonamenti − risparmio) ÷ giorni fino al prossimo stipendio. Si ricalcola ogni giorno.
- **Spese fisse e scadenze annuali** (bollo, assicurazione) con accantonamento automatico.
- **Conti secondari** e piano "soldi da spostare".
- **Registrazione automatica** delle spese dalle notifiche di Google Wallet, della banca e degli SMS, tramite MacroDroid.
- **Blocco** con PIN e impronta, **backup mensile** su Google Drive.

I dati restano solo sul telefono di chi usa l'app: questo repository contiene solo il codice.
